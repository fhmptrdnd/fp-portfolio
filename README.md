# FP Portfolio

### Beyond the Surface — An Exploration of Visual Stories.

**FP Portfolio** adalah website portfolio kreatif yang dirancang sebagai ruang pamer digital imersif untuk menampilkan berbagai karya visual, mulai dari fotografi, videografi, motion graphics, hingga desain digital.

Mengusung konsep galeri minimalis dengan dominasi warna hitam dan permukaan air reflektif, website ini menghadirkan pengalaman visual yang berbeda dari website portfolio konvensional.

Setiap karya ditampilkan seolah-olah mengambang di atas permukaan air, menciptakan perpaduan antara seni visual, ruang, cahaya, dan refleksi.

---

## Konsep & Filosofi

*Beyond the Surface* merepresentasikan gagasan bahwa setiap karya memiliki cerita yang lebih dalam daripada sekadar apa yang terlihat.

Galeri ini dirancang untuk memberikan ruang bagi setiap karya agar dapat dinikmati secara lebih personal, tanpa distraksi elemen visual yang berlebihan.

Pendekatan desain menggabungkan estetika minimalis, atmosfer sinematik, dan eksplorasi teknologi web interaktif.

### Arah Visual

- **Dark Environment** — Ruang hitam dengan atmosfer misterius dan elegan.
- **Reflective Surface** — Permukaan air gelap yang menghadirkan refleksi setiap karya.
- **Floating Artwork** — Karya visual ditampilkan seolah mengambang di atas permukaan air.
- **Ambient Lighting** — Pencahayaan lembut untuk menciptakan kedalaman ruang.
- **Minimalist Typography** — Tipografi sederhana yang menjaga fokus pada karya.
- **Immersive Experience** — Pengalaman menjelajahi galeri dengan navigasi yang intuitif.

## Pengalaman Visual

### 01. Ruang Galeri

Lingkungan visual dirancang dengan dominasi warna hitam untuk menciptakan kesan ruang tanpa batas.

### 02. Refleksi Air

Permukaan air menjadi elemen utama yang menghubungkan karya dengan lingkungan galeri, menghadirkan ilusi kedalaman dan pantulan cahaya melalui manipulasi visual CSS.

### 03. Eksplorasi Karya

Pengunjung dapat menjelajahi koleksi visual melalui galeri horizontal yang dilengkapi dengan navigasi scroll.

### 04. Detail dan Interaksi

Setiap karya ditampilkan dengan informasi judul, kategori, dan tahun pembuatan.

## Teknologi

FP Portfolio dikembangkan menggunakan teknologi web modern dengan pendekatan component-based development untuk menghasilkan website yang responsif, terstruktur, dan mudah dikembangkan.

| Teknologi | Implementasi |
|---|---|
| React.js | Membangun antarmuka website menggunakan komponen yang reusable. |
| TypeScript | Mengelola struktur data portfolio dan memberikan type safety pada komponen. |
| Vite | Menjalankan development server dan mengoptimalkan proses build. |
| CSS3 | Mengatur layout, tipografi, animasi, efek refleksi air, dan responsive design. |
| HTML5 | Menyusun struktur semantik halaman website. |

### Implementasi Utama

- Component-based architecture menggunakan React.
- Pengelolaan data karya melalui TypeScript.
- CSS transforms untuk menciptakan efek refleksi gambar.
- CSS gradients dan overlays untuk membangun atmosfer pencahayaan.
- CSS animations untuk memberikan kesan pergerakan pada permukaan air.
- Responsive layout menggunakan CSS media queries.
- Lazy loading untuk membantu mengoptimalkan pemuatan gambar.
